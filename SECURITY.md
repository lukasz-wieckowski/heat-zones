# Security policy

Heat Zones controls heating, so please report security problems privately.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting: open the **Security** tab of this
repository and choose **Report a vulnerability**. Include the Heat Zones and Home Assistant versions, what you did,
what happened, and what you expected.

You will get an answer within 7 days. Fixes for confirmed issues ship in a patch release, with credit if you want it.

## Supported versions

Only the latest release receives security fixes.
